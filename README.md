A running archive of my solutions to competitive programming problems — written mostly in **C++**, solved as I work through **Codeforces** (and other judges) as part of ongoing practice.

This repo isn't a curated "best solutions" showcase — it's closer to a lab notebook: a record of problems attempted, approaches tried, and progress made over time.

---

## 📁 Repository Structure

Files are named after the problem's judge ID, so you can jump straight from a submission to its source.

```
Coding_Solutions/
├── 1857A.cpp     # Codeforces Round — Problem 1857A
├── 1858A.cpp     # Codeforces Round — Problem 1858A
└── ...           # more solutions added as I solve them
```

**Naming convention:** `<ContestNumber><ProblemLetter>.cpp`
For example, `1857A.cpp` is my solution to problem **A** from **Codeforces Round 1857**.

> As the collection grows, this may be reorganized into folders by platform (`codeforces/`, `leetcode/`, `codechef/`) or by topic/difficulty — check back for structural updates.

---

## 🚀 Running a Solution

Each file is a self-contained, single-file C++ solution. To compile and run one locally:

```bash
g++ -std=c++17 -O2 -o solution 1857A.cpp
./solution < input.txt
```

Or pipe input directly:

```bash
g++ -std=c++17 -O2 -o solution 1857A.cpp && ./solution
```
